# Linux Monitoring v2.0

*The project was written from task S21.* <img src="materials/images/heart_21_x10.gif" alt="drawing" width="20" height="20"/>

![linux_monitoringv2.0.png](materials/images/linux_monitoringv2.0.png)

**Linux Monitoring v2.0** — это набор bash-скриптов и инструментов для генерации файлов, анализа логов и мониторинга состояния системы.
Проект включает автоматическое создание файловой структуры, генерацию и анализ логов **nginx**, а также настройку **Prometheus** и **Grafana** для мониторинга ресурсов системы.

## Part 1: Генератор файлов
[Директория со скриптом.](src/01)

**Описание:**  
Скрипт создает вложенные директории и файлы по заданным параметрам:
- Создает папки и файлы с именами, сформированными из переданных символов.
- Добавляет дату запуска скрипта к имени объектов.
- Создает файлы указанного размера.
- Ведет лог всех созданных файлов и директорий.
- Останавливает работу при достижении порога свободного места менее 1 Гб.

**Использование:**
```bash
bash main.sh /opt/test 4 az 5 az.az 3kb
```

## Part 2: Засорение файловой системы
[Директория со скриптом.](src/02)

**Описание:**  
Скрипт создает папки и файлы в директориях /var /usr /opt /home файловой системы:
- Создает до 100 вложенных папок.
- Использует случайное количество файлов в каждой папке.
- Проверяет свободное место через df -h /.
- Записывает лог с информацией обо всех созданных объектах.
- Выводит время начала и окончания работы скрипта.

**Использование:**
```bash
bash main.sh az az.az 3Mb
```

## Part 3: Очистка файловой системы
[Директория со скриптом.](src/03)

**Описание:**
Скрипт удаляет файлы и директории, созданные в [Part 2](#part-2-засорение-файловой-системы), несколькими способами:

1. По лог-файлу;
2. По диапазону даты и времени создания;
3. По маске имени.

**Использование:**
```bash
bash main.sh <cleanup_method>
```

*Available cleanup methods:*

**1 - by log file, 2 - by creation date and time, 3 - by name mask.**

## Part 4: Генератор логов
[Директория со скриптом.](src/04)

**Описание:**  
Скрипт генерирует **5 лог-файлов** nginx в формате `combined`:

- Каждый лог содержит записи за отдельный день.
- Количество записей в логах генерируется случайным образом.
- Генерируются случайные **IP-адреса**, **HTTP-методы**, **URL**, **user-agent** и **коды ответа**.
- Даты внутри логов упорядочены по возрастанию.

**Использование:**
```bash
bash main.sh
```

## Part 5: Мониторинг
[Директория со скриптом.](src/05)

**Описание:**  
Скрипт анализирует nginx-логи из [Part 4](#part-4-генератор-логов) с использованием `awk`.

В зависимости от параметра запуска выводит:
1. Все записи, отсортированные по коду ответа;
2. Уникальные IP-адреса;
3. Запросы с кодами ошибок;
4. Уникальные IP среди ошибочных запросов.

**Использование:**
```bash
bash main.sh <mode>
```

*Available modes:*

**1 - sort by response code, 2 - unique IPs, 3 - error requests, 4 - unique error IPs.**

## Part 6: GoAccess
[Подробнее](src/06/Report_DO4_06.md)

**Описание:**  
Для анализа логов используется утилита **GoAccess**:

- Выполняется анализ логов nginx.
- Формируется web-интерфейс со статистикой.
- Отображаются данные по запросам, IP-адресам и HTTP-кодам.

**Использование:**
```bash
goaccess access.log -o report.html --log-format=COMBINED
```

## Part 7: Prometheus и Grafana
[Подробнее](src/07/Report_DO4_07.md)

**Описание:**  
Настроены **Prometheus** и **Grafana** для мониторинга системы:

- Мониторинг загрузки CPU.
- Мониторинг использования оперативной памяти.
- Мониторинг свободного места на диске.
- Мониторинг операций ввода/вывода.

Дополнительно:
- Выполнено тестирование нагрузки с помощью `stress`.
- Проведен анализ изменения системных метрик под нагрузкой.
